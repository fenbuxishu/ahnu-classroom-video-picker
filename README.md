# 课堂实录视频选择器

一个适用于安徽师范大学课堂实录播放中心的 Chrome 扩展。它会在课程页面中汇总全部课次及其教师/学生相机视角，让用户先查看、再勾选需要的视频交给 Chrome 下载。

> 非安徽师范大学官方产品。请仅下载自己有权访问和使用的课程内容，并遵守学校规定、版权要求与课堂成员隐私。

## 功能

- 自动读取当前课程的全部课次；
- 按课次展示教师相机和学生相机视角；
- 显示视频时长、单个文件大小和已选总容量；
- 支持全选、按课次选择、仅选教师相机或仅选学生相机；
- 下载时按课程、课次和相机视角自动分类命名；
- 每次重新读取页面接口，避免使用已经过期的视频地址；
- 纯本地运行，不需要额外服务器。

## 安装

### 从 Release 安装

1. 在仓库的 [Releases](../../releases) 页面下载最新版 ZIP；
2. 解压 ZIP；
3. 在 Chrome 地址栏打开 `chrome://extensions/`；
4. 打开右上角的“开发者模式”；
5. 点击“加载已解压的扩展程序”；
6. 选择解压后的插件文件夹。

### 从源码安装

克隆本仓库，然后在 `chrome://extensions/` 中选择本仓库目录作为“已解压的扩展程序”。

## 使用

1. 登录安徽师范大学相关系统；
2. 打开某一门课程的“课堂实录”播放页面；
3. 刷新页面，右侧会自动显示“课堂实录视频选择器”；
4. 按课次或相机类型勾选视频；
5. 点击底部的“下载已选视频”。

插件也可以通过页面右下角的“视频总览”按钮或 Chrome 工具栏中的扩展按钮打开。

视频默认保存到：

```text
下载/课堂实录/课程名/课次日期与节次/相机名称_视角编号.mp4
```

实际根目录取决于 Chrome 的下载设置。如果启用了“下载前询问每个文件的保存位置”，批量下载时 Chrome 可能逐个询问。

## 权限说明

| 权限 | 用途 |
| --- | --- |
| `downloads` | 将用户主动勾选的视频交给 Chrome 下载，并自动组织文件名 |
| `https://mlb.ahnu.edu.cn/*` | 在课堂实录页面显示选择器并读取当前账号有权访问的课次信息 |
| `https://dbfw.ahnu.edu.cn/*` | 读取视频文件大小并下载用户勾选的视频 |

插件不会上传账号、Cookie、课程数据或视频地址，也不会在外部服务器保存这些信息。视频地址通常含临时鉴权参数，因此只在当前页面会话中读取和使用。

## 项目结构

```text
manifest.json   Chrome Manifest V3 配置
content.js      课次读取、页面面板和勾选交互
panel.css       页面面板样式
background.js   Chrome 下载任务和文件命名
```

## 开发与检查

项目不依赖构建工具或第三方运行时。修改代码后，在 `chrome://extensions/` 点击插件卡片上的“重新加载”，再刷新课堂实录页面。

可以用以下命令检查 JavaScript 和清单文件语法：

```bash
node --check content.js
node --check background.js
jq empty manifest.json
```
